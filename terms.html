Información general Estos Términos de Servicio regulan el uso de **FERSHO BOT** (en adelante, "el Bot"), una aplicación diseñada para funcionar dentro de la plataforma Discord. Uso permitido FERSHO BOT debe utilizarse de manera responsable y de acuerdo con: * Estos Términos de Servicio. * La Política de Privacidad de FERSHO BOT. * Los Términos de Servicio de Discord. * Las Normas de la Comunidad de Discord. * Las leyes y regulaciones aplicables. Funcionalidades FERSHO BOT puede proporcionar diferentes funcionalidades para servidores de Discord, incluyendo, entre otras: * Moderación y administración de servidores. * Comandos y herramientas de utilidad. * Sistemas de entretenimiento. * Reproducción de música, cuando dicha función esté disponible. * Configuración personalizada por servidor. * Sistemas de interacción y entretenimiento. * Otras funcionalidades que puedan incorporarse en el futuro. Las funcionalidades pueden cambiar, actualizarse, suspenderse o eliminarse sin previo aviso. ## 1.4. Responsabilidad del usuario Los administradores y propietarios de los servidores son responsables de configurar y utilizar correctamente FERSHO BOT. FERSHO BOT no se hace responsable del contenido publicado por los usuarios de un servidor ni de las acciones realizadas por administradores o miembros de una comunidad. ## 1.5. El servicio puede experimentar: * Mantenimiento. * Actualizaciones. * Errores técnicos. * Interrupciones del servidor. * Problemas relacionados con Discord u otros servicios externos. * Cambios en las APIs o funcionalidades de terceros. No se garantiza que el Bot esté disponible de forma ininterrumpida o permanente. ## 1.6. Suspensión o terminación Podemos limitar, suspender o finalizar el acceso a determinadas funcionalidades del Bot cuando exista un uso que: * Incumpla estos Términos de Servicio. * Incumpla las reglas de Discord. * Sea ilegal o abusivo. * Pueda perjudicar al Bot, sus servicios o a otros usuarios. * Suponga un uso malicioso o fraudulento. Política de Privacidad ## 2.1. Introducción Esta Política de Privacidad explica qué información puede recopilar, utilizar y almacenar FERSHO BOT cuando el Bot es añadido a un servidor o utilizado por sus miembros. Nuestro objetivo es recopilar únicamente la información necesaria para proporcionar y mejorar las funcionalidades del Bot. ## 2.2. Información que podemos recopilar Dependiendo de las funcionalidades utilizadas, FERSHO BOT puede procesar determinada información relacionada con Discord. Esta información puede incluir: * ID del usuario de Discord. * ID del servidor de Discord. * ID de canales. * ID de roles. * Nombre o identificador del servidor. * Configuraciones relacionadas con el servidor. * Información necesaria para ejecutar comandos. * Información técnica necesaria para detectar errores y mantener el servicio. **Importante:** FERSHO BOT no debe almacenar información que no sea necesaria para proporcionar sus funcionalidades. ## 2.3. Mensajes de Discord Dependiendo de las funcionalidades y permisos utilizados por FERSHO BOT, el Bot puede procesar mensajes enviados en canales donde tenga acceso. El procesamiento puede ser necesario para: * Detectar comandos. * Ejecutar funciones de moderación. * Responder a interacciones. * Detectar determinadas acciones configuradas por los administradores. FERSHO BOT no utiliza el contenido de los mensajes para crear perfiles publicitarios de los usuarios. Si el Bot almacena contenido de mensajes de manera persistente, esta sección deberá actualizarse para describir exactamente qué información se almacena y durante cuánto tiempo. ## 2.4. Información que no recopilamos intencionalmente FERSHO BOT no solicita intencionalmente información personal sensible como: * Contraseñas. * Tokens de Discord. * Información bancaria. * Datos de tarjetas de crédito. * Documentos de identidad. * Información médica. Los usuarios nunca deben proporcionar este tipo de información mediante comandos, mensajes o sistemas de FERSHO BOT. ## 2.5. Cómo utilizamos la información La información procesada por FERSHO BOT puede utilizarse para: * Ejecutar comandos solicitados por los usuarios. * Proporcionar funcionalidades de moderación. * Guardar configuraciones de los servidores. * Mantener las preferencias configuradas por los administradores. * Detectar errores y problemas técnicos. * Mantener la seguridad del servicio. * Mejorar el funcionamiento del Bot. La información no se utilizará para vender datos personales de los usuarios. ## 2.6. Almacenamiento de datos Los datos necesarios para el funcionamiento de FERSHO BOT pueden almacenarse en servidores utilizados para operar el servicio. El período de almacenamiento depende del tipo de información. Las configuraciones de servidores pueden mantenerse mientras FERSHO BOT permanezca instalado en el servidor o mientras sean necesarias para proporcionar el servicio. Los datos que ya no sean necesarios pueden eliminarse de acuerdo con los procedimientos de mantenimiento y eliminación utilizados por FERSHO BOT. ## 2.7. Compartición de información FERSHO BOT no vende información personal de sus usuarios. La información puede ser procesada por proveedores técnicos necesarios para proporcionar el servicio, como proveedores de alojamiento, bases de datos o infraestructura. Cuando sea necesario utilizar servicios externos, estos proveedores pueden procesar determinados datos exclusivamente para proporcionar la infraestructura o funcionalidad correspondiente. ## 2.8. Seguridad Se aplican medidas razonables para proteger la información procesada por FERSHO BOT frente a accesos no autorizados, pérdida, alteración o divulgación. Sin embargo, ningún sistema conectado a Internet puede garantizar una seguridad absoluta. ## 2.9.
