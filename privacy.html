# Política de Privacidad — FERSHO BOT **Última actualización:** 26 de agosto de 2026 Esta Política de Privacidad explica cómo **FERSHO BOT** ("el Bot") recopila, utiliza, almacena y protege determinada información cuando se utiliza en servidores de Discord. Al utilizar FERSHO BOT, aceptas las prácticas descritas en esta Política de Privacidad. ## 1. Responsable FERSHO BOT es un bot independiente desarrollado para la plataforma Discord. Para cualquier consulta relacionada con privacidad o tratamiento de datos, puedes contactar mediante: **Correo electrónico:** [ugzombie16@gmail.com] ## 2. Información que podemos recopilar FERSHO BOT puede procesar determinada información proporcionada por Discord o generada mediante el uso de sus funciones. Dependiendo de las funciones habilitadas en un servidor, esto puede incluir: * ID de usuario de Discord. * ID del servidor de Discord. * ID de canales. * ID de roles. * Nombre de usuario, nombre para mostrar o apodo de Discord. * Información necesaria para ejecutar comandos solicitados por los usuarios. * Configuraciones del Bot establecidas por los administradores de un servidor. * Información relacionada con el uso de comandos y funciones del Bot. FERSHO BOT no necesita recopilar información como contraseñas, información bancaria, números de tarjetas de crédito o mensajes privados de Discord. ## 3. Cómo utilizamos la información La información procesada por FERSHO BOT puede utilizarse para: * Ejecutar los comandos solicitados por los usuarios. * Proporcionar las funciones del Bot. * Guardar y aplicar configuraciones específicas de cada servidor. * Mantener y mejorar el funcionamiento del Bot. * Detectar errores, abusos o usos indebidos. * Mantener la seguridad y estabilidad del servicio. * Responder a solicitudes de soporte. La información no se utilizará para vender datos personales a terceros. ## 4. Mensajes y contenido de Discord FERSHO BOT puede necesitar acceder a determinados mensajes o contenido de Discord cuando una función o comando específico lo requiere. El Bot no está diseñado para almacenar permanentemente conversaciones privadas o mensajes personales de los usuarios salvo que una función específica indique claramente lo contrario. Cuando sea técnicamente necesario procesar contenido para ejecutar una función, dicho contenido se utilizará únicamente para proporcionar esa función. ## 5. Almacenamiento de datos La cantidad y el tipo de información almacenada pueden variar dependiendo de las funciones utilizadas por el servidor. Cuando sea necesario almacenar información, procuraremos conservar únicamente los datos necesarios para proporcionar las funciones correspondientes. Los datos podrán eliminarse cuando: * Ya no sean necesarios para proporcionar el servicio. * El servidor deje de utilizar FERSHO BOT. * El usuario o administrador correspondiente solicite su eliminación, cuando corresponda. * Sea necesario eliminarlos por razones de seguridad o mantenimiento. ## 6. Compartición de información FERSHO BOT no vende ni alquila información personal. La información puede ser procesada por proveedores de infraestructura o servicios tecnológicos utilizados para operar el Bot, únicamente cuando sea necesario para proporcionar, mantener o proteger el servicio. También podremos divulgar información cuando sea necesario para cumplir con obligaciones legales, proteger nuestros derechos o prevenir actividades fraudulentas, abusivas o ilegales. ## 7. Discord FERSHO BOT funciona dentro de la plataforma Discord. El uso de Discord está sujeto a los propios términos y políticas de privacidad de Discord. FERSHO BOT no controla las prácticas de privacidad, almacenamiento o procesamiento de datos realizadas directamente por Discord. Puedes consultar las políticas oficiales de Discord en su sitio web. ## 8. Seguridad Tomamos medidas razonables para proteger la información procesada por FERSHO BOT contra acceso no autorizado, pérdida, alteración o divulgación. Sin embargo, ningún sistema conectado a Internet puede garantizar una seguridad absoluta. ## 9. Derechos y solicitudes de eliminación Dependiendo de la legislación aplicable, puedes tener derechos relacionados con tus datos personales, incluyendo: * Solicitar información sobre los datos que procesamos. * Solicitar la corrección de información incorrecta. * Solicitar la eliminación de determinados datos. * Solicitar información sobre cómo se utilizan tus datos. Para realizar una solicitud relacionada con privacidad, contacta mediante: **Correo electrónico:** [ugzombie16@gmail.com] Las solicitudes podrán requerir información suficiente para verificar que la persona que realiza la solicitud está autorizada para hacerlo. ## 10. Datos de menores FERSHO BOT no está destinado específicamente a recopilar información de menores. No solicitamos deliberadamente información personal innecesaria de menores. Si consideras que se ha proporcionado información personal de un menor de forma indebida, puedes contactarnos para solicitar su revisión y eliminación cuando corresponda. ## 11.
